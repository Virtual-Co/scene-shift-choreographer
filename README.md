# Scene-Shift Choreographer

## What it does

A static, offline 2D rhythm toy. Drag the candidate vector, tap on the beat, and switch between a harmless prop and a protected-person text symbol to see an authored scene rule project the candidate. The paper's concept is fused with beat-timed steering. This is a conceptual visualization, not the paper's generator, learned references, sampler integration, CBF-QP, robotics, reported results, or a safety guarantee.

## Run

Open `demo/index.html` directly in a modern browser. No server or build step is needed.

### Usage

1. Open `demo/index.html` from this folder.
2. Drag the coral endpoint to steer the candidate vector.
3. Tap or click elsewhere on the stage to check your timing against the beat.
4. Activate the scene switch to compare the protected-person scene with the prop scene.

## Test

No automated test suite is included. For a visual smoke check, open the page, drag the glowing endpoint, switch scenes, and tap the stage near its 1.2-second pulse.

## Build/package

There is no build step. `demo/index.html` is self-contained.
